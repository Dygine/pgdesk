Read this first. It is the state of PGuru at the end of 12 September 2026 and it
is written for whoever picks this up next, including a fresh AI assistant with no
memory of how any of it got here.

---

## 1. What this is

PGuru is PG and hostel management software for Indian owners. Two halves:

- **Owner side** — branches, buildings, floors, rooms, individual beds,
  residents, ID documents, rent, invoices, complaints, food, laundry, gate
  attendance, staff roles, reports
- **Seeker side** — a public search where people look for a room, find PGs on a
  map, and send enquiries. Most competitors do not have this half.

Plus a **public marketing website** and a **master-admin CMS** that edits it.

### Database connection — where to get it

**The connection string is NOT in this repo and must never be committed.**

Get it from **Render → `pgdesk-api` → Environment → `DATABASE_URL`**.

Shape:
```
postgresql+psycopg://<user>:<password>@ep-jolly-salad-b3zyapz6-pooler.c-4.ap-southeast-1.aws.neon.tech/neondb?sslmode=require
```

Three things that bite people:

1. **The `+psycopg` is required.** `config.py` rejects a plain `postgresql://`
   URL, because psycopg2 is not installed and the failure would otherwise
   surface as a confusing runtime error.
2. **Use the `-pooler` host for the running app**, and the host *without*
   `-pooler` for `alembic upgrade head` if migrations hang.
3. **Migrations do NOT run automatically on boot.** `main.py` only checks the
   connection. `HANDOVER.md` says otherwise and is wrong. Run them by hand or
   put `alembic upgrade head` in the Render build command.

## 5. Running it locally

```powershell
# backend
cd backend
pip install -r requirements.txt
$env:DATABASE_URL = "<from Render>"
$env:SECRET_KEY   = "<any 32+ char string>"
python -m alembic upgrade head
python -m uvicorn app.main:app --reload --port 8000

# frontend
cd frontend
npm install
npm run dev
```

PowerShell 5.1 has no `&&`. Use `;` or separate lines.

## 6. Things that will confuse you if nobody says them

**`frontend/src/data/sitePresets.js` is generated.** It mirrors `PRESETS` in
`backend/app/services/site_service.py`. Edit the Python, then regenerate — do not
hand-edit the JS. It exists so the website renders complete before the API
answers (the API is on a free tier that sleeps; without this the homepage was a
blank stub for 50 seconds).

**The APK has no bundled screens.** `capacitor.config.json` sets
`server.url = https://pgguru.in`, so the app loads the live website. **Deploying
the website IS the app update.** No APK rebuild needed for UI or logic changes.
Only rebuild the APK if `capacitor.config.json`, a native plugin, or the Android
project changes.

**`npm run build:android` strips the APK from `dist/` before syncing.** Without
that step the app bundles a 28 MB copy of itself. See `scripts/strip-apk.mjs`.

**Only `arm64-v8a` and `armeabi-v7a` are built.** x86 was dropped to save 12 MB.
The APK will not install on a standard Windows emulator — add `x86_64` back to
`abiFilters` in `android/app/build.gradle` if you need that.

**The release keystore is NOT in this repo** and must never be. It is
`pgguru-release.jks`, backed up in the owner's Google Drive. Losing it means a
new Play Store listing from zero.

## 7. Do not switch off pgdesk.dygine.com

`server.url` is compiled into every installed APK. Older APKs point at
`pgdesk.dygine.com` and always will. Removing that domain from the `pgdesk`
Render service bricks every installed app at once, with no route back.

`LegacyDomainBanner.jsx` shows an in-app "update your app" prompt to anyone still
loading from the old host. Leave the old domain attached until you are confident
nobody is on an old build.

## 9. What was built on 12 September 2026

### Listing photos (migration 0015)
Up to 6 photos per branch, each under 5 KB, camera or upload, compressed on the
device. Colour-preserving compressor (`photoScan.js`) separate from the
greyscale document one (`docScan.js`) — a grey photo of a bedroom sells nothing.

### Session fix (migration 0015)
**The bug:** `_revoke_all_for()` revoked every session on every device whenever
reuse detection fired. The usual trigger was not theft but a deploy — the server
rotates a token, is replaced mid-reply, and the app retries with a spent token.
One unlucky refresh signed out every phone.

**The fix:** token families. Each login mints a family id; every rotation
inherits it. Reuse detection now revokes only the presenting device's chain.
Signing out, password change and deactivation still revoke everything everywhere.

Browser sessions cut to **24 hours** (`BROWSER_SESSION_HOURS`). Installed apps
keep a renewing 10-year session. `is_native` is stored on the token row, so a
stripped header can no longer downgrade an app session to a browser one.

### Map on Find PG
Leaflet over OpenStreetMap. Drop a pin anywhere, type an area, or use GPS — all
three produce the same lat/lng/label. Results as green dots, blue radius ring.
Lazy-loaded: 43.55 KB gzipped in its own chunk.

Also fixed: Leaflet ships z-index up to 1000, above this app's modals (z-80). A
map behind a dialog painted straight through it. `.leaflet-container` now has
`isolation: isolate`.

### The website and its CMS (migration 0016)
Six public pages, all content in `site_blocks` / `site_images`, edited at
**Master → Website**. 16 editable sections. Seven custom SVG illustrations in the
brand colours — an earlier version pointed at a random-photo service and put a
mountain in fog on the homepage of a PG product.

### Domain migration
Everything moved from dygine.com to pgguru.in. New APKs point at pgguru.in; old
ones keep working via the legacy banner.

### APK size
45 MB → 13 MB. Removed a 28 MB self-copy and two emulator-only architectures.

### SEO
`robots.txt`, `sitemap.xml` (8 URLs), JSON-LD structured data. Search Console
verified, sitemap submitted, all pages requested for indexing.

### Legal
`/privacy` and `/terms`, written against the actual code — the real permissions,
the 5 KB document store, Razorpay, Brevo, Render, Neon, OpenStreetMap.
**Not written by a lawyer.** India's DPDP Act 2023 applies and a product holding
Aadhaar scans has obligations no template covers. Get it reviewed.

### Play Store
Developer account **Dygine Software Solutions** created, $25 paid, identity
verification submitted. Release keystore generated and backed up. Signed AAB
built. See `PLAYSTORE.md` for the listing copy and the Data safety answers.
