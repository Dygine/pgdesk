How it works

One resident, from enquiry to checkout. Every step below is a real screen, and each one updates the ledger the next step reads from.

  1. Add the resident

    Name, phone, KYC and the branch they are joining. They count against your plan's resident limit, so you always know where you stand.

  2. Assign a bed

    Pick from beds that are genuinely free right now. Two staff members cannot assign the same bed — the server locks it.

  3. Check in

    Rent, deposit and stay terms are agreed, and the first invoice is raised in the same transaction. Nothing is half-done if something fails.

  4. Bill every month

    One rent run raises invoices for the whole branch. Rent, food, laundry, electricity, maintenance and late fees are separate lines, so a resident can see what they are paying for.

  5. Record and verify payment

    Reception records it, a manager verifies it. Only verified payments move the balance — which is what stops the ledger drifting from the bank.

  6. Run the property day to day

    Attendance, gate scans, visitors, gate passes, meals, laundry slots and complaints — all against the same resident record.

  7. Transfer or check out

    Move them to another room or another branch, or settle up and release the bed. The bed is free for the next resident the moment it happens.

Installing the Android app

PGDesk is not on the Play Store yet, so Android will ask you to confirm. Three taps.

  1. Download the file

    Tap the button below. Your browser will ask you to confirm — choose Download anyway.

  2. Allow the install

    Open the downloaded file. Android will say installing from this source is blocked. Tap Settings and turn on Allow from this source.

  3. Install and open

    Go back, tap Install, then Open. PGDesk appears on your home screen.

Android shows these warnings for any app installed outside the Play Store. You can switch the permission back off afterwards and PGDesk will keep working.

Already have the app? You do not download it again for updates — just open PGDesk and it refreshes itself. A fresh download is only needed if we tell you the app itself changed. Prefer no install at all? Open the web version and use your browser's Add to Home screen for an app‑style icon.

What it does not do yet

Worth knowing before you plan around it.

  • No email, SMS or WhatsApp sending. Notifications appear inside the app. Nothing is sent out.
  • No PDF invoices. Invoices are on screen and export to CSV; a printable document is next.
  • KYC stores a reference, not the document. You record the ID number; the file itself lives wherever you keep it today.
  • No iPhone app. The web version works on any phone.
